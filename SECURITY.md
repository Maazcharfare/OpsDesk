# Security policy

## Supported version

Security fixes are made against the current default branch. Older snapshots may not receive updates.

## Reporting a vulnerability

Please do not open a public issue with exploit details. If this repository is hosted on GitHub with private vulnerability reporting enabled, use the repository's **Security → Report a vulnerability** flow. Otherwise, contact the repository owner privately and include the affected version, impact, and a minimal reproduction. Do not include real credentials, customer data, or production database contents.

OpsDesk is a portfolio project and deployment starter. It has not received an independent penetration test. Production service checks remain disabled by default because DNS rebinding and outbound access require host-level controls.
